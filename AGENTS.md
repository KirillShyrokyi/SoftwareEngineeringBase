# Instructions for AI Agents

`SoftwareEngineeringBase` is a **public repository**.

Before creating or editing any public content, follow `AI_POLICY.md` and `CONTRIBUTING.md`.

## Non-negotiable privacy rule

Never publish personal data, private conversation content, or information from private repositories merely because you can access it.

Access is not permission to publish.

Use private material only if the repository owner explicitly authorizes publication of that specific material in this repository.

If there is any uncertainty, do not publish it.

## Safe examples

Prefer neutral educational examples created for this repository, such as:

- `Order`
- `Payment`
- `User`
- `Product`

Do not reproduce private source code, internal names, architecture, business logic, configuration, credentials, tokens, secrets, or other closed context.

## Learning workflow

The repository should represent the learner's actual established understanding.

Do not mark a topic as understood or write a final personal formulation until that understanding has been demonstrated in the learning dialogue.

### Autonomous learning checkpoints

During a learning dialogue, the AI is responsible for deciding when a coherent block of demonstrated knowledge is ready to be saved to the repository. The learner should not need to remind the AI to save progress.

Do not save after every answer. Choose natural checkpoints, such as after a topic or a closely related group of topics has been completed and the learner has demonstrated the required understanding.

When such a checkpoint is reached and repository write access is available, save the established learning progress without waiting for a separate reminder or asking whether it should be saved.

Only save understanding that has actually been demonstrated. Do not mark incomplete, untested, or merely assumed knowledge as understood or mastered.
