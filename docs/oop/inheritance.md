# Inheritance / Наследование

## Главная идея

**Inheritance / наследование** описывает отношение между типами, когда производный класс является более конкретным видом базового класса.

```text
Animal
  ↑
Mammal
  ↑
Dog
```

`Dog IS-A Animal` — собака является животным.

```csharp
class Animal
{
    public void Eat() { }
}

class Dog : Animal
{
    public void Bark() { }
}
```

Объект `Dog` может использовать доступные ему унаследованные члены `Animal`.

## Один объект, а не два

```csharp
Dog rex = new Dog();
```

Создаётся один объект реального типа `Dog`. В нём есть состояние и поведение, определённые базовыми классами, а также собственная часть `Dog`.

Наследование не создаёт два отдельных объекта `Animal` и `Dog`.

## Тип переменной и реальный тип объекта

```csharp
Animal rex = new Dog();
```

Здесь `Animal` — объявленный тип переменной `rex`, а `Dog` — реальный тип созданного объекта. Переменная хранит ссылку на этот объект.

```csharp
rex.Eat();  // OK
rex.Bark(); // compile error
```

Через переменную доступны члены её объявленного типа и его базовых типов. Сам объект при этом остаётся объектом `Dog`.

## Цепочка наследования

```csharp
class Animal
{
    public void Eat() { }
}

class Mammal : Animal
{
    public void Breathe() { }
}

class Dog : Mammal
{
    public void Bark() { }
}
```

```csharp
Dog rex = new Dog();

rex.Eat();
rex.Breathe();
rex.Bark();
```

Все три вызова доступны: `Dog` наследуется от `Mammal`, а `Mammal` — от `Animal`.

Если ссылка имеет тип `Mammal`:

```csharp
Mammal rex = new Dog();

rex.Eat();      // OK
rex.Breathe();  // OK
rex.Bark();     // compile error
```

## private и protected

```csharp
class Animal
{
    private string _name;
    protected int Age;
}

class Dog : Animal
{
    public void Birthday()
    {
        Age++;          // OK
        // _name = "";  // compile error
    }
}
```

- `private` — прямой доступ есть только внутри типа, который объявил член.
- `protected` — доступ есть внутри базового класса и производных классов.

Приватное состояние базового класса не исчезает из производного объекта. Производный класс просто не получает к нему прямого доступа. Базовый класс может управлять им через собственные методы. Это поддерживает **encapsulation / инкапсуляцию**.

## Конструкторы не наследуются

Конструктор базового класса не становится конструктором производного класса.

```csharp
class Animal
{
    public Animal(string name)
    {
    }
}

class Dog : Animal
{
    public Dog(string name) : base(name)
    {
    }
}
```

При создании объекта:

```text
new Dog("Rex")
    ↓
Dog(string name)
    ↓
base(name)
    ↓
Animal(string name)
    ↓
тело Animal
    ↓
тело Dog
    ↓
объект Dog готов
```

Базовый конструктор выполняется до тела конструктора производного класса.

Если доступен конструктор базового класса без параметров, вызов `: base()` обычно добавляется неявно.

## this(...) и base(...)

```csharp
public Dog() : this("Rex")
{
}

public Dog(string name) : base(name)
{
}
```

- `this(...)` вызывает другой конструктор того же класса.
- `base(...)` выбирает конструктор базового класса.

```text
Dog()
 ↓ this("Rex")
Dog("Rex")
 ↓ base("Rex")
Animal("Rex")
```

Ключевое слово `base` также может явно обращаться к доступному члену базового класса:

```csharp
base.Eat();
```

## IS-A и HAS-A

Наследование подходит для отношения **IS-A**:

```text
Dog IS-A Animal
```

Но не для отношения **HAS-A**:

```text
Car HAS-A Engine
```

Машина не является двигателем, поэтому `Car : Engine` неверно моделирует отношение. Связь HAS-A ведёт к отдельной теме — **composition / композиции**.

## Итог

Наследование — не просто способ избежать повторения кода. Оно выражает отношение между типами: производный тип является более конкретным видом базового типа.

При этом модификаторы доступа продолжают действовать, а **инкапсуляция** базового класса не исчезает из-за наследования.
