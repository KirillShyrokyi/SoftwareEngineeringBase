# HashSet<T> — множество уникальных элементов

[← C#](index.md) · [Roadmap](../roadmap.md)

## Простая модель

`HashSet<T>` — коллекция уникальных элементов. Для неё главное не позиция элемента, а вопрос: **принадлежит ли элемент множеству?**

```csharp
HashSet<int> processedOrders = new();

processedOrders.Add(101);
processedOrders.Add(205);
processedOrders.Add(101);
```

Повторный `101` не создаёт второй элемент.

## Основные операции

- `Add(value)` возвращает `true`, если новый элемент добавлен, и `false`, если он уже существовал.
- `Contains(value)` отвечает `true` или `false`: есть ли элемент в множестве.
- `Remove(value)` возвращает `true`, если существующий элемент был удалён.
- `Count` показывает количество уникальных элементов.

## Операции множеств

```text
IntersectWith → оставить общее
UnionWith     → собрать всё уникальное вместе
ExceptWith    → убрать из первого множества то, что есть во втором
```

Эти операции изменяют множество, на котором вызываются.

## Почему HashSet

`HashSet<T>` полезен, когда порядок и позиция не важны, а важно быстро проверять наличие уникального элемента: например, хранить ID уже обработанных заказов.

Если каждому ID нужно сопоставить дополнительное значение, например дату обработки, задача уже естественнее выражается через `Dictionary<TKey, TValue>`.

## Hash и Set

```text
Set  → множество уникальных элементов
Hash → хеширование используется внутри для организации поиска
```

`HashSet` хранит сами элементы, а не коллекцию их хешей. Совпадение hash code ещё не означает равенство элементов: после нахождения кандидата нужна проверка equality.

Для собственных типов правило равенства может потребовать отдельного определения. Детали `Equals`, `GetHashCode` и `IEqualityComparer<T>` относятся к более глубокой теме equality.

## Связь с другими коллекциями

```text
List<T>
→ последовательность элементов
→ порядок имеет значение
→ повторы допустимы

Dictionary<TKey, TValue>
→ уникальный ключ связан со значением

HashSet<T>
→ уникальные элементы
→ основной вопрос: «есть такой элемент или нет?»
```

## Подтверждённая формулировка

`HashSet` подходит, когда порядок не важен и нужен чёткий ответ, было/есть такое уникальное значение или нет. Если к уникальному идентификатору нужно привязать дополнительные данные, лучше выбрать `Dictionary`.
