# Methods — методы

[← C#](index.md) · [Roadmap](../roadmap.md)

## Что это простыми словами

Метод — это именованный блок действий, который можно вызывать из других мест программы. Ему можно передавать разные аргументы, чтобы одна и та же логика работала с разными входными значениями.

## Какую проблему решает

Если одинаковая операция нужна много раз, её неудобно копировать во все места программы. Метод позволяет держать эту логику в одном месте, вызывать её многократно и при изменении правила менять сам метод, а не каждую копию кода.

## Mental model

```text
ARGUMENTS
   ↓
METHOD CALL
   ↓
PARAMETERS
   ↓
LOCAL VARIABLES + LOGIC
   ↓
RETURN
   ↓
CALLER
```

Каждый вызов — отдельное выполнение метода со своими параметрами и локальными переменными.

## Как работает

В объявлении метода `x` и `y` — **parameters (параметры)**. В вызове `Calculate(4, 3)` значения `4` и `3` — **arguments (аргументы)**.

```csharp
static int Calculate(int x, int y)
{
    int result = x + y;

    if (result > 10)
    {
        return result * 2;
    }

    return result;
}

int a = Calculate(4, 3); // 7
int b = Calculate(8, 5); // 26
```

Первый вызов завершается со своими `x`, `y` и `result`. Второй вызов начинает новое выполнение с другим набором значений.

`return` возвращает значение вызывающему коду и завершает текущее выполнение метода.

## Типичная ошибка

Если метод объявлен с возвращаемым типом, например `int`, нельзя оставить обычный путь выполнения без возвращаемого значения:

```csharp
static int Calculate(int x, int y)
{
    int result = x + y;

    if (result > 10)
    {
        return result * 2;
    }
}
```

Если условие ложно, выполнение доходит до конца, но методу нечего вернуть вызывающему коду. Поэтому такой код не компилируется.

## Связи с другими темами

```text
arguments → parameters
              ↓
            scope
              ↓
       local variables
              ↓
        control flow
              ↓
           return
```

Методы связывают уже знакомые понятия: параметры получают входные значения, локальные переменные существуют внутри выполнения метода, условия выбирают путь выполнения, а `return` передаёт результат наружу.

## English vocabulary

- **method** — метод;
- **method call** — вызов метода;
- **parameter** — параметр в объявлении метода;
- **argument** — конкретное значение при вызове;
- **local variable** — локальная переменная;
- **return value** — возвращаемое значение;
- **caller** — код, который вызвал метод;
- **code path** — возможный путь выполнения кода.

## Моя формулировка

Методы нужны, чтобы вынести определённую операцию в одно место, многократно вызывать её с разными аргументами и удобно менять эту операцию централизованно. Каждый вызов проходит отдельно со своими параметрами и локальными значениями. Если метод должен вернуть `int`, каждый обычный путь его выполнения должен вернуть значение.
