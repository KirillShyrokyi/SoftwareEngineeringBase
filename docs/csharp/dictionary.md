# Dictionary<TKey, TValue> — словарь ключ → значение

## Простое объяснение

`Dictionary<TKey, TValue>` хранит не просто последовательность элементов, а пары **ключ → значение (key → value)**.

Например:

```text
"Anna" → 20
"Bob"  → 25
```

Здесь имя удобно использовать как ключ, а возраст — как связанное с ним значение.

## Mental Model

```text
Dictionary<TKey, TValue>
        ↓
множество пар key → value
        ↓
key позволяет найти связанное value
```

Один элемент словаря при переборе представлен типом `KeyValuePair<TKey, TValue>`.

## Основные операции

```csharp
Dictionary<string, int> ages = new Dictionary<string, int>();

ages.Add("Anna", 20);
ages["Bob"] = 25;

int bobAge = ages["Bob"];
```

Ключи должны быть уникальными. Повторный `Add` с существующим ключом приводит к `ArgumentException`. Присваивание через индексатор обновляет значение существующего ключа, а для отсутствующего ключа создаёт новую пару.

`Count` показывает количество пар в словаре.

## Безопасный поиск

Чтение через индексатор требует существующего ключа. Если ключа нет, возникает `KeyNotFoundException`.

Когда наличие ключа заранее неизвестно, удобно использовать `TryGetValue`:

```csharp
if (ages.TryGetValue("Bob", out int age))
{
    Console.WriteLine(age);
}
```

Здесь два результата:

```text
return bool → найден ли ключ
out value   → найденное значение
```

Если ключ отсутствует, `TryGetValue` возвращает `false`, а `out int` получает значение по умолчанию — `0`.

## Изменение значения

```csharp
if (stock.TryGetValue(product, out int amount))
{
    stock[product] = amount + 1;
}
else
{
    stock.Add(product, 1);
}
```

Эта логика увеличивает существующее значение или создаёт новую пару.

## Удаление

```csharp
bool removed = stock.Remove("Banana");
```

`Remove(key)` удаляет пару по ключу и возвращает `true`, если ключ существовал. Если такого ключа уже нет, возвращается `false`.

## Перебор

```csharp
foreach (KeyValuePair<string, int> pair in stock)
{
    Console.WriteLine(pair.Key);
    Console.WriteLine(pair.Value);
}
```

`stock` — весь словарь, а `pair` — одна текущая пара. Поэтому у `pair` есть `Key` и `Value`.

## Ссылочная семантика

`Dictionary<TKey, TValue>` — ссылочный тип.

```csharp
Dictionary<string, int> second = first;
```

Это не создаёт второй словарь: `first` и `second` ссылаются на один объект.

```csharp
Dictionary<string, int> second =
    new Dictionary<string, int>(first);
```

Здесь `new` создаёт отдельный объект словаря и копирует в него пары.

## Когда выбирать Dictionary

`List<T>` удобен, когда нужна последовательность элементов и работа с ними как с коллекцией по позициям.

`Dictionary<TKey, TValue>` удобен, когда у значения есть естественный уникальный ключ, по которому его нужно получать.

Например, последовательность температур можно хранить в `List<int>`. Если задача меняется и нужно хранить температуру **по дате**, естественной становится модель:

```text
дата → температура
```

и для неё подходит словарь.

## Типичные ошибки

- считать ключ пользовательским индексом;
- повторно вызывать `Add` с уже существующим ключом;
- читать `dictionary[key]`, не убедившись, что ключ существует;
- путать `return bool` у `TryGetValue` со значением, которое метод записывает через `out`;
- считать `KeyValuePair` методом: это тип, представляющий одну пару ключ-значение.

## Связи

```text
Dictionary
   ├── key / value
   ├── TryGetValue → return + out
   ├── foreach → KeyValuePair
   └── reference type → несколько ссылок могут указывать на один объект
```

## Моя формулировка

Для обычной последовательности значений отдельный логический ключ может быть не нужен, поэтому подходит `List<T>`. Если значение естественно связано с уникальным идентификатором — например, имя → возраст или дата → температура — удобно выбрать `Dictionary<TKey, TValue>`, где этот идентификатор становится ключом.
