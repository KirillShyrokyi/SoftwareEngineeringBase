# Control Flow & Loops

Статус: 🟢 Понимаю

Эта заметка сохраняет подтверждённую модель выбора ветки выполнения и повторения кода.

## Conditions

Сравнения создают `bool`. `&&` требует истинности обеих частей, `||` — хотя бы одной, `!` меняет boolean-значение на противоположное. `=` присваивает, `==` сравнивает равенство, `!=` — неравенство.

## if / else

`if / else if / else` — одна цепочка выбора: выполняется максимум одна подходящая ветка. Несколько отдельных `if` — независимые проверки, поэтому могут выполниться несколько блоков. Вложенный `if` создаёт дополнительное решение внутри уже выбранного пути.

## switch

`switch` удобен, когда вопрос звучит как «какой это вариант значения?».

```text
if     → выполняется ли условие?
switch → какой это вариант значения?
```

Несколько `case` могут вести к общей логике. Для строк важно учитывать регистр символов.

## for

```text
initialization
     ↓
condition ── false ──→ stop
     ↓ true
    body
     ↓
   update
     └──────────────→ condition
```

При индексном обходе массива длины `Length` допустимые индексы идут от `0` до `Length - 1`. Поэтому условие `i <= numbers.Length` в конце попытается обратиться к несуществующему `numbers[Length]`.

Это понимание индексации не закрывает arrays как отдельную тему.

## foreach

`foreach` выражает идею «для каждого элемента» и подходит для последовательного обхода, когда не требуется вручную управлять индексом.

## while

`while` повторяет тело, пока условие остаётся `true`. Условие проверяется до очередного выполнения тела.

```csharp
int number = 10;
while (number > 0)
{
    number -= 3;
    Console.WriteLine(number);
}
```

Вывод: `7, 4, 1, -2`. После `-2` условие снова проверяется, становится `false`, и цикл завершается. Если состояние условия никогда не меняется, цикл может стать бесконечным.

## Mental model

```text
decision
├─ if      → проверить условие
└─ switch  → выбрать вариант значения

repetition
├─ for     → управлять шагами/счётчиком
├─ foreach → для каждого элемента
└─ while   → повторять, пока условие true
```

Эта заметка фиксирует подтверждённую модель control flow и не закрывает arrays или collections как отдельные темы.
