# Out parameters — выходные параметры

[← C#](index.md) · [Roadmap](../roadmap.md)

## Что это простыми словами

`out` — выходной параметр (**output parameter**): место, куда метод обязан записать результат для вызывающего кода.

## Mental model

```text
METHOD
  ├── return -> status / main result
  └── out    -> output value
```

Старое значение переменной для `out` не является входными данными метода. Метод должен сам присвоить выходное значение до нормального завершения.

## Зачем нужен

Иногда нужно отдельно сообщить, удалась ли операция, и одновременно отдать полученное значение:

```csharp
bool success = int.TryParse("123", out int number);
```

Здесь `return` передаёт признак успеха, а `out` — полученное число.

## Связь с ref

```text
ref -> значение уже должно существовать;
       метод может его читать и изменять.

out -> начальное значение не требуется;
       метод обязан записать результат.
```

## Типичная ошибка

Нельзя читать `out` до присваивания:

```csharp
static void SetValue(out int x)
{
    Console.WriteLine(x);
    x = 10;
}
```

Сначала метод должен присвоить `x`, после чего значение можно читать.

## Моя формулировка

`out` подходит, когда значение является результатом работы метода: ему не нужно старое значение извне, ему нужен вывод, который сделала операция. Метод сам обязан записать этот результат.
