# Exceptions — try, catch, finally и throw

[← C#](index.md) · [Roadmap](../roadmap.md)

## Основная идея

Исключение (*exception*) прерывает обычный ход выполнения. `int.Parse("abc")` выбрасывает `FormatException`, а целочисленное деление на ноль — `DivideByZeroException`.

```csharp
try
{
    Console.WriteLine("A");
    int value = int.Parse("abc");
    Console.WriteLine("B");
}
catch (FormatException)
{
    Console.WriteLine("C");
}
finally
{
    Console.WriteLine("D");
}
Console.WriteLine("E");
```

Вывод: `A`, `C`, `D`, `E`. Если заменить `"abc"` на `"123"`, вывод: `A`, `B`, `D`, `E`.

`try` обозначает область обработки исключений, но не проверяет код заранее. После выброса исключения оставшиеся инструкции в `try` пропускаются. Подходящий `catch` может обработать исключение, после чего выполнение продолжается.

## Подходящий тип исключения

`int.Parse("0")` успешно возвращает число `0`. Но `10 / int.Parse("0")` выбрасывает `DivideByZeroException`, поэтому `catch (FormatException)` его не обработает. Если подходящего обработчика нет, исключение передаётся вызывающему коду; оно не обязательно немедленно завершает всю программу.

## Finally

`finally` выполняется при обычном завершении `try` и при распространении исключения, даже если `catch` не подошёл. Сам по себе `finally` не обрабатывает исключение. Есть особые ситуации, например принудительное завершение процесса, когда выполнение `finally` не гарантируется.

## Throw

`throw new Exception("Ошибка")` создаёт и выбрасывает новое исключение. `throw;` внутри `catch` повторно выбрасывает пойманное исключение, сохраняя исходную информацию о его происхождении.

```csharp
try
{
    Console.WriteLine("A");
    throw new Exception("Ошибка");
}
catch (Exception)
{
    Console.WriteLine("B");
    throw;
}
finally
{
    Console.WriteLine("C");
}
Console.WriteLine("D");
```

Вывод: `A`, `B`, `C`. `D` не выполняется: исключение продолжает распространяться. Если удалить `throw;`, вывод станет `A`, `B`, `C`, `D`.

## Mental model

- `try` — область, где может возникнуть исключение;
- `catch` — обработчик подходящего типа;
- `finally` — блок завершения, который обычно выполняется и при ошибке;
- `throw;` — повторная передача исключения;
- отсутствие подходящего обработчика здесь означает поиск обработчика выше по цепочке вызовов.
