# C# — язык и фундамент

> Этот раздел превращает синтаксис C# в рабочую модель языка: данные, значения, область видимости, управление потоком, методы, коллекции, LINQ, асинхронность и память.

## Что здесь будет

- Variables — переменные
- Values — значения
- Types — типы
- Scope — область видимости
- Methods & Parameters — методы и параметры
- Control Flow — управление выполнением
- Collections — коллекции
- LINQ
- Async / Await
- Memory Model — модель памяти
