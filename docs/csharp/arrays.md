# Arrays — массивы

[← C#](index.md) · [Roadmap](../roadmap.md)

## Простая модель

Массив (**array**) — объект фиксированной длины, содержащий элементы одного заданного типа. Доступ к элементу идёт по индексу, начиная с нуля.

```text
values -> [10][20][30]
index      0   1   2
Length = 3
```

## Основные правила

- `Length` — количество элементов.
- Допустимые индексы: от `0` до `Length - 1`.
- Обращение за границы приводит к `IndexOutOfRangeException`.
- Элемент можно читать и изменять через индекс.
- Размер созданного массива фиксирован.
- Все элементы соответствуют типу массива.

## Default values

При `new T[length]` элементы получают значения по умолчанию:

```text
int    -> 0
bool   -> false
string -> null
```

## for и foreach

`foreach` удобен, когда нужно пройти по элементам. `for` нужен, когда важен индекс или требуется изменять элементы через индекс.

```csharp
for (int i = 0; i < temperatures.Length; i++)
{
    temperatures[i] = temperatures[i] + 1;
}
```

## Reference semantics

Массив — reference type.

```csharp
int[] first = { 10, 20, 30 };
int[] second = first;
```

Здесь две переменные ссылаются на один объект массива.

Если создать второй массив через `new`, это уже другой объект, даже если элементы имеют те же значения.

## Моя формулировка

Массив хранит набор элементов одного типа. Индексы начинаются с нуля, поэтому при четырёх элементах допустимы индексы 0–3. `Length` показывает количество элементов, а в цикле используется `i < Length`, чтобы не выйти за границы. Массив имеет фиксированный размер и является объектом: две переменные могут ссылаться на один массив, а два отдельных `new` создают разные объекты.
