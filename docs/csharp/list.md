# List<T> — изменяемая коллекция

[← C#](index.md) · [Roadmap](../roadmap.md)

## Простая модель

`List<T>` — коллекция элементов одного типа, количество которых может изменяться во время работы программы.

```text
List<int>
   ↓
[10] [20] [30]
Count = 3
```

В отличие от массива фиксированной длины, список позволяет добавлять, удалять и вставлять элементы.

## Основные операции

```csharp
List<int> numbers = new List<int>();

numbers.Add(10);
numbers.Add(20);
numbers.Add(30);
```

- `Add(value)` — добавить элемент в конец;
- `Remove(value)` — удалить первое найденное совпадение и вернуть `bool`;
- `RemoveAt(index)` — удалить элемент по индексу;
- `Insert(index, value)` — вставить элемент в указанную позицию;
- `Count` — текущее количество элементов;
- `list[index]` — получить или изменить элемент по индексу.

Индексы начинаются с нуля, как и у массива. Последний существующий элемент находится по индексу `Count - 1`.

## Remove и RemoveAt

```text
Remove(20)   -> удалить первое значение 20
RemoveAt(1)  -> удалить элемент с индексом 1
```

После удаления следующие элементы сдвигаются влево.

## Insert

```csharp
numbers.Insert(1, 99);
```

означает: вставить значение `99` на позицию с индексом `1`. Для вставки допустима позиция `Count`, потому что это добавление нового элемента в конец, хотя чтение `list[Count]` выходит за существующие индексы.

## Когда List<T> удобнее массива

Если количество элементов заранее неизвестно или должно изменяться, `List<T>` удобнее массива фиксированной длины.

## Reference semantics

`List<T>` — reference type.

```csharp
List<string> second = first;
```

Здесь две переменные ссылаются на один объект списка.

```csharp
List<string> second = new List<string>(first);
```

Здесь создаётся новый объект списка, поэтому последующие добавления в `second` не меняют `first`.

## Моя формулировка

`List<T>` — коллекция заданного типа, которую удобно использовать, когда заранее неизвестно, сколько элементов нужно хранить. Элементы можно добавлять, удалять и вставлять, а `Count` показывает их текущее количество. Индексация начинается с нуля. Если присвоить один список другой переменной без `new`, обе переменные будут ссылаться на одну коллекцию; `new` создаёт отдельный объект списка.
