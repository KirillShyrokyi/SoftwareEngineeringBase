# AI Privacy & Publication Policy

This repository is public.

Any AI, LLM, coding assistant, autonomous agent, IDE assistant, bot, or other automated system working with `SoftwareEngineeringBase` must treat the repository as a **public publication boundary**.

## Mandatory rule

Technical access does not equal publication permission.

Do **not** use or publish:

- personal information about the repository owner;
- private conversation content;
- content from private repositories;
- private source code, architecture, business logic, internal names, files or configuration;
- credentials, tokens, secrets or keys;
- private contextual information that can reveal closed material indirectly.

This prohibition applies even when such information is available through memory, connected tools, repository access, previous conversations, IDE context, agent context or any other source.

## Explicit approval requirement

Private material may be published only when the owner explicitly authorizes **that specific material** for publication in this public repository.

General access, prior discussion, similarity to a learning example, or relevance to the current topic does not count as approval.

If permission is ambiguous, do not publish the material.

## Safe default

Use:

- general Software Engineering knowledge;
- public technical sources;
- neutral teaching examples created specifically for this repository;
- content already public in `SoftwareEngineeringBase`;
- material explicitly approved for publication.

When an explanation could be inspired by a private project, replace private details with neutral examples such as `Order`, `Payment`, `User` or `Product`.

## Learning-state rule

Educational notes should reflect concepts that have actually been established in the learning dialogue. Do not present an unverified assumption about the learner's understanding as a completed or mastered topic.

## Core principle

> Public knowledge only. Private context remains private unless the owner explicitly approves publication of the specific material.
